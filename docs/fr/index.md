ghstats collecte vos dépôts, langages, releases et le trafic via l'API GitHub, puis génère des cartes SVG sombres et claires pour le README de votre profil. L'historique de trafic est conservé au-delà des 14 jours que GitHub affiche.

Il s'utilise comme Action GitHub composite ou comme CLI, et aucun nom de dépôt privé n'apparaît dans les sorties.
