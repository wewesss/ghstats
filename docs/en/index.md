ghstats collects your repositories, languages, releases and traffic through the GitHub API and renders dark and light SVG cards for your profile README. The traffic history is kept beyond the 14 days GitHub shows.

It runs as a composite GitHub Action or as a CLI, and no private repository name appears in any output.
